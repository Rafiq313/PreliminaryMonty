# PreliminaryMonty

Нативный порт для Linux/SDL2.
Этот проект собирается без оригинального ATR, ROM, графики, звука и лабиринта.

## Сборка

Нужны CMake 3.20+, компилятор C11, SQLite3 и SDL2.

```sh
cmake -S . -B build
cmake --build build
```

## DEB-пакет (Debian, Ubuntu, Kubuntu)

Сборка пакета требует также `dpkg-dev` и `file`:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
cpack --config build/CPackConfig.cmake -G DEB -B build/packages
```

CPack определяет архитектуру и необходимые версии библиотек по системе сборки.
Пакет для более новой системы может не устанавливаться на старую; для поддержки
старых дистрибутивов собирайте пакет в самой старой поддерживаемой системе.

Установка загруженного пакета (пример для amd64):

```sh
sudo apt install ./preliminary-monty_0.1.0-1_amd64.deb
preliminary_monty --load-atr-image /путь/к/game.atr --play
```

После первого импорта запускайте `preliminary_monty --play`.
Пакет устанавливает исполняемый файл в `/usr/bin` и документацию в
`/usr/share/doc/preliminary-monty`; оригинальные ресурсы в него не входят.
Личная база данных создаётся при импорте от имени обычного пользователя.

## Работа в VS Code (Linux)

Откройте именно каталог `PreliminaryMonty` через **File → Open Folder**.
Установите рекомендованные расширения **CMake Tools** и **C/C++**; для отладки
нужен GDB (`sudo apt install gdb` в Kubuntu/Ubuntu).

- **Ctrl+Shift+B** — настроить CMake и собрать Debug-версию.
- **Terminal → Run Task → Import ATR** — первый импорт; VS Code запросит
  полный путь к вашему ATR. Путь вводится без кавычек, пробелы допустимы.
- **Run Task → Play** — обычный запуск после импорта.
- **Run Task → Import ATR and play** — импорт и немедленный запуск.
- **F5** — запуск с отладчиком; доступны также **Play (always light)**
  и **Import ATR and play** в списке конфигураций запуска.
- **Run Task → List mazes** — показать лабиринты локальной базы.

Перед запуском и отладкой проект автоматически собирается. Точки останова
ставятся в `src/*.c`; настройки IntelliSense берутся из созданного CMake
`build/compile_commands.json`. Для SDL-окна нужна графическая сессия Linux.
Пути к ATR и личные файлы не записаны в общие настройки проекта.

## Первый запуск и локальный импорт

Пользователь предоставляет собственный оригинальный ATR, полученный из
правомерного источника. Программа ничего не скачивает.

```sh
./build/preliminary_monty --load-atr-image /path/to/game.atr --play
```

Поддерживается распознанная структура данных Atari-версии со 100 комнатами:
ATR с секторами 128 байтов, таблица из 102 указателей на 101 поток,
10 смещений этажей и корректные записи команд/ссылок. Поиск структуры
не зависит от имени файла или точного хеша образа. Образы с нераспознанной
или повреждённой структурой данных отклоняются. Импортёр не исполняет машинный код ATR.

В SQLite создаётся либо заменяется только `native`, импортируются локальные
ресурсы, применяются наши исправления комнат 37, 64 и 82. Затем все комнаты
проверяются на девяти сложностях. Всё это одна транзакция: ошибка не заменяет
существующий лабиринт; другие лабиринты сохраняются. Повторный импорт
восстанавливает native из образа с теми же исправлениями.

По умолчанию база создаётся в `$XDG_DATA_HOME/PreliminaryMonty/mazes.sqlite3`,
либо `$HOME/.local/share/PreliminaryMonty/mazes.sqlite3`.
Своя база задаётся явно:

```sh
./build/preliminary_monty --maze-db /path/to/mazes.sqlite3 --load-atr-image /path/to/game.atr
./build/preliminary_monty --maze-db /path/to/mazes.sqlite3 --play
```

Без `--play` команда импорта только создаёт/обновляет БД и завершает работу.
После импорта ATR для следующих запусков не нужен:

```sh
./build/preliminary_monty --play
./build/preliminary_monty --always-light --play
./build/preliminary_monty --list-mazes
./build/preliminary_monty --maze native --play
```

WASD/стрелки — движение, Space — прыжок, R — новая игра, Escape — выход.
SQLite хранит типизированные команды лабиринта и локальный кэш ресурсов
`maze_resources(kind='atari-assets-v1')`. База без этого кэша потребует импорта.
Данные графики/звука извлекаются из ATR, не исполняются как программа.

## Публикация и права

Для публикации предназначены наш код, схема SQLite, пустая ресурсная разметка
и инструкции исправлений. Оригинальные ATR/ROM, заполненные SQLite,
извлечённые ресурсы, скриншоты и аудиозаписи в проект не включены.
Наш C-код написан после анализа оригинала: clean-room происхождение не заявлено.

## Состав проекта

- `src` — игра, импорт ATR, пустое хранилище ресурсов, схема SQLite и исправления.
- `include` — заголовки игрового кода.
- `.vscode` — общие настройки сборки, запуска и отладки в VS Code.
- `CMakeLists.txt` — сборка игры; `README.md` — инструкции; `LICENSE` — условия лицензии.
